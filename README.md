# hostess-js

The Hostess SDK for JavaScript/TypeScript. A pnpm + TypeScript monorepo.

## Packages

- [`@hostess/nextjs`](packages/nextjs) — native insights for Next.js.

Future: Express, Hono, and generic Node helpers reusing the same collector
pipeline.

## Development

```bash
pnpm install
pnpm build
pnpm test
```
